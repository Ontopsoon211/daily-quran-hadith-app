# Daily Quran & Hadith App

A simple Flutter app for daily Quran verses and hadith, with search, favorites, and reflection topics.

## Getting started

1. Install Flutter SDK.
2. Run:
   ```bash
   flutter pub get
   flutter run
   ```

## Features

- Daily Quran verse of the day
- Daily hadith of the day
- Search Quran verses and hadith
- Bookmark favorites
- Modern Islamic-inspired UI
